Customer Segmentation using K-Means

Project Overview

This project uses the K-Means clustering algorithm to group mall customers based on their annual income and spending score.

Dataset

The Mall Customers dataset contains customer details, including annual income and spending score.

Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

Algorithm

K-Means clustering is used to divide customers into 5 clusters. The Elbow Method is also used to help identify a suitable number of clusters.

Visualizations

- Customer Segmentation Plot
- Elbow Method Plot

How to Run

1. Install the required libraries:
   "pip install pandas matplotlib scikit-learn"
2. Run the Python file:
   "python customer_segmentation.py"

Outcome

The project groups customers with similar income and spending patterns to help understand customer segments.
